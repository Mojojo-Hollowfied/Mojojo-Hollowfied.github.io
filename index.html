Install in a minute

Nebula Files is installed directly from this site rather than from the Play Store.

  1. Buy and download. Buy on Gumroad (card or PayPal) and download NebulaFiles-v2.7.apk from your receipt or email.
  2. Allow installs from your browser. When Android asks, open Settings and turn on Install unknown apps for the browser you downloaded with (for example Chrome).
  3. Open the downloaded file. Tap the download notification, or find NebulaFiles-v2.7.apk in your Downloads folder, then tap Install.
  4. Launch and grant access. Open Nebula Files and allow file access so it can manage your storage.

Play Protect may warn you. Because the app is sideloaded rather than installed from the Play Store, Play Protect can show a warning for an app it hasn't scanned before. Tap More details and then Install anyway.

Everything in one place

A complete file manager, your cloud drives, storage tools, a media player, a PDF editor and a code editor in one app.

File manager

Browse internal storage, SD cards and USB drives. Copy, move, rename and pin favorites.

  • Fast search with filters
  • Trash, so deletes can be undone
  • ZIP, RAR, 7z and TAR archives
  • Storage analyzer and large file cleaner

Dropbox & OneDrive

Native, built-in access to your own cloud files. Sign in once to browse, open, upload, download and manage them alongside your local storage. FTP and SFTP servers are supported too.

SD/USB format & secure wipe

Guided formatting for SD cards and USB drives, plus a quick wipe that erases every file and an optional secure wipe that fills free space with zeros so deleted files can't be recovered. Both erase data permanently.

Powerful media player

Three engines, ExoPlayer, FFmpeg and VLC, so it plays nearly any video or audio format, including files other players refuse.

Pro code editor

  • Up to 20 tabs, restored after restart
  • Syntax highlighting for 73 languages
  • Autocomplete
  • Regex find & replace
  • Live HTML and Markdown preview
  • Built-in JavaScript runner

PDF reader & editor

Read, search and mark up PDFs without another app.

  • Zoom, thumbnails, outline and night mode
  • Highlight, draw, add notes and text
  • Fill forms and sign
  • Merge, split, reorder and compress
  • Password-protected PDFs

11 languages

English, Spanish, Portuguese, French, German, Hindi, Arabic, Chinese, Japanese, Indonesian and Russian.

A dark, cosmic design: nebula wallpaper behind every screen, frosted-glass cards and glowing green, cyan and magenta accents.
